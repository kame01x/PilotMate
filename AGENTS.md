\# PilotMate Instructions



\## General Rules



\- Inspect the existing code before making changes.

\- Do not delete files or folders without asking me first.

\- Do not install or remove packages without asking me first.

\- Do not change the project architecture without explaining why.

\- Do not modify authentication or security code without explaining the changes.

\- Never expose API keys, passwords, or secrets.

\- Never put secrets directly in source code.

\- Use environment variables for secrets.

\- Reuse existing components and code when possible.

\- Keep the implementation simple and maintainable.



\## Before Major Changes



\- Explain what you plan to change and why.

\- Ask for my approval before destructive or major architectural changes.



\## After Changes



\- Check for errors.

\- Run relevant tests when available.

\- Clearly explain what was changed.
